# Handoff acceptance evidence

Built on Anna's `5c644a7` with its stricter touch-landing judge. **39 tests pass**;
**16 real Drake runs** cover four frozen controllers, two committed charts and
both unified Sekai presets. There are no execution, load or guarded-policy errors.
Low completion scores are preserved as model outcomes.

See [per-run results](validation.md), [machine-readable checks](validation.json),
[test log](tests.log), and [resource preflight](preflight.json).

This is entry-point validation, not a new 64-run benchmark. Historical camera
scores/GIFs remain tied to their older judge. The [handoff](../../docs/HANDOFF.md)
contains the exact smoke/full commands and checkpoint retrieval/checksum steps.
